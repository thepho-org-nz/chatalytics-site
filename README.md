# chatalytics-site

Public overview page for **chatalytics** — trustworthy natural-language analytics for New Zealand primary care.

This repo contains a single self-contained static page (`index.html`) and its brand assets. No build step, no dependencies, no tracking. It is published via GitHub Pages.

## Local preview

```sh
python3 -m http.server 8080
# open http://localhost:8080
```

## Deploy

Served by GitHub Pages from the `main` branch (root). Edits pushed to `main` go live automatically.

To customise copy or contact details, edit `index.html` (search for `EDIT:`).
